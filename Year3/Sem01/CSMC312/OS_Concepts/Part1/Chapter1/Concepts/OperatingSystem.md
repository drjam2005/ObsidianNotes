# Operating System
- What is it?
    - It is a program that basically acts as an intermediary between a user of a computer and the underlying hardware of said computer
- Goals of an Operating System:
    1. Execute user programs and make solving of such user problems much easier.
    2. Make the computer system easier to use
    3. Use the underlying hardware in an efficient manner

# Computer System Structure
- Computer system can be divided into four main components:
    1. Hardware 
        - provides basic computing resouces
            -> CPU, memory, I/O devices
    2. Operting System
        - Controls and coordinates use of hardware among various applications and users
    3. Applicatoin programs
        - define ways in which the system programs are used to solve computing problems of the users
            -> Word processors, compilers, web browsers, database systems, video games, etc...
    4. Users
        - Ones of which will be using the computer system
            -> People, machines, other computers...

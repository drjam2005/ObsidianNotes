# Operating System formal Definition
- Operating System is a **resource allocator**
    - Manages all resources (I/O, Memory, CPU, etc...)
    - Decides between conflicting requests for efficient  and fair resource use
- Operating System is a **control program**
    - Controls execution of programs to prevent errors and improper use of such computer


- It's informal definition can be found here [[./OperatingSystem.md|What is an Operating System?]]

- There is no universally accepted definition
- "Everything a vendor ships when you order an operating system" is a decent approximation
    - But this varies wildly
- "The one program running at all times on the computer" is the **kernel**.
- Everything else is either
    - A system program (ships with the operating system), or
    - an applicaton program
